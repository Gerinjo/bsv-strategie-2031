# Entscheidungen

Dieser Bereich dokumentiert strategische Entscheidungen und ihre Begründung dauerhaft. Neue Entscheidungen werden aus [`_vorlage.md`](_vorlage.md) erstellt und fortlaufend nummeriert, zum Beispiel `0001-strategieprozess-starten.md`.

Ein Eintrag wird erst als **beschlossen** markiert, wenn Datum, zuständiges Gremium und Quelle eindeutig feststehen.
