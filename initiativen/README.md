# Initiativen

Initiativen sind konkrete, zeitlich und organisatorisch fassbare Vorhaben, die zu mindestens einem strategischen Ziel beitragen.

Neue Initiativen werden aus [`_vorlage.md`](_vorlage.md) angelegt. Der Dateiname sollte kurz und eindeutig sein, zum Beispiel `ehrenamts-onboarding.md`.
