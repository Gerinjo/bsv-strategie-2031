# Protokolle

Hier werden Workshops, Interviews und Sitzungen zum Strategieprozess dokumentiert. Neue Protokolle verwenden [`_vorlage.md`](_vorlage.md) und einen Dateinamen im Format `JJJJ-MM-TT-kurztitel.md`.

Personenbezogene Aussagen werden nur aufgenommen, wenn dies erforderlich und freigegeben ist. Im Regelfall werden Themen und Ergebnisse zusammengefasst.
